# Auditoría de referencia ecommerce — 18 de septiembre de 2026

## Referencia revisada

Se revisó la estructura pública de Fybeca como referencia de experiencia de compra. La página consultada solicita seleccionar el sector de entrega, por lo que no se tomaron estilos ni contenido; solo patrones generales de navegación ecommerce.

## Mejoras aplicadas a Reyna del Cisne

- Se mantuvo el catálogo en una página independiente.
- Se conservó la separación de frameworks:
  - Inicio institucional: Bootstrap Grid.
  - Compras: Tailwind CSS.
- Se mantuvieron categorías, buscador visual, grid de productos y carrito lateral.
- Se añadió un contador de productos visibles.
- Se añadió una etiqueta de orden visual con “Recomendados”, personalizada con la paleta de la farmacia.
- No se añadieron componentes predeterminados de Bootstrap ni una copia visual de Fybeca.

## Pendientes para una futura versión

- Búsqueda real.
- Ordenamiento funcional por precio o recomendación.
- Filtros de disponibilidad y marcas.
- Selector de sector o zona de entrega cuando se confirmen las zonas reales.
- JavaScript para cantidades, total y persistencia del carrito.
