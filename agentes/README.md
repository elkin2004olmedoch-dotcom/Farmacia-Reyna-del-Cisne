# Agentes locales del proyecto

Esta carpeta guarda definiciones locales de agentes para trabajar con el proyecto de Farmacia Reyna del Cisne.

## Archivos

- `codex-programador.md`: agente de programación y desarrollo.
- `gemini-busqueda.md`: agente orientado a búsqueda e investigación.
- `claude.md`: agente generalista de análisis y redacción.
- `open-code-auditoria.md`: agente de auditoría de código y calidad.

## Uso

Puedes abrir cualquiera de estos archivos y copiar el prompt base en la herramienta compatible que estés usando (Codex, Gemini, Claude o Open Code).

## Objetivo del proyecto

Este sitio es una landing page para Farmacia Reyna del Cisne, con HTML/CSS y contenido estático.

## Recomendación

- Usar Codex para implementar cambios y features.
- Usar Gemini para investigar requisitos, referencias y contenidos.
- Usar Claude para redacción, análisis y estructuración.
- Usar Open Code para auditoría, validación y revisiones de calidad.
